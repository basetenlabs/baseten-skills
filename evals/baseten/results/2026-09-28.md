## Takeaways

- Make `baseten loops exec` the only recommended command for managed Loops client execution. It preserves the active Baseten CLI workspace context.
- Keep checkpoint deployment guidance concrete: name the REST endpoint or MCP tool, require confirmation, distinguish sampler and trainer checkpoints, and forbid blind retries.
- Keep the skill PR gated until the Baseten CLI command, Management API endpoint, MCP tool, and linked docs are published.
